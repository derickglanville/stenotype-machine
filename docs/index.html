How to use Verbatim Step-by-step guide

New to stenography? Start with microphone dictation. The 22-key keyboard is a separate way to enter trained steno chords; you do not need to press keys while dictating.

1. Start a proceeding

  1. Tap New session and enter a name in Proceeding.
  2. Choose a speaker, then tap Insert speaker to add a label to the transcript.
  3. Choose dictation, the steno keyboard, or type directly in the transcript. You can combine these methods.

2. Capture spoken words

  1. Choose the Spoken language.
  2. Tap Start dictation and allow microphone access if prompted.
  3. Wait for Listening, then speak clearly. Keep the app visible and watch the status.
  4. Tap Stop dictation before reviewing text or changing sessions. If capture stops on its own, tap Start again.
  5. Tap the transcript to correct names, punctuation, and missed words. Select and insert a new speaker label when needed; speakers are not identified automatically.

Audio is not saved. Your browser’s speech service may process audio remotely. Use capture only when permitted; the result is a draft requiring review.

3. Try the stenotype keyboard

  1. Leave Tap to build chord checked on iPhone.
  2. Tap left T, left H, and vowel E. The chord display should read THE.
  3. Tap Write stroke. The starter dictionary inserts “the.”
  4. Tap a selected key again to deselect it, or use Clear chord before writing.
  5. On iPad, turn off tap mode to press several keys together. Release all keys to write the stroke. Landscape gives your fingers more room.

The keyboard has 22 steno keys plus a number bar. Left and right consonants differ. For example, number bar + left S writes 1. Unknown strokes appear in brackets instead of guessed words.

4. Save and reopen your work

  1. Look for Saved on this device. Edits are saved automatically in this browser.
  2. For a cloud copy, tap Sign in with Google and use dglanville@gmail.com.
  3. Tap Save to cloud and wait for Cloud copy saved. Tap it again after further edits; cloud saving is not automatic.
  4. Choose an existing proceeding from the session menu beside New session. Stop dictation before switching.
  5. On another device, sign in to load cloud sessions. If already signed in, reload to retrieve them. Differing local content is kept as a separate cloud copy.

Device drafts stay in this browser after sign-out and are not encrypted locally. Clearing browser data can remove them. Avoid editing the same cloud session on two devices at once.

5. Export or restore a session

  1. Tap Export .txt for a readable draft transcript you can share or print.
  2. Tap Backup .json to keep a restorable copy including the raw steno strokes. Save the downloaded file somewhere you can find again.
  3. To restore, open Stroke history & dictionary, then choose the backup under Restore session backup.
  4. The restored backup opens as a separate session. Export and back up important work regularly.

6. Expand your steno vocabulary

  1. Open Stroke history & dictionary to inspect the most recent raw strokes.
  2. Under Import dictionary, choose a Plover-format JSON dictionary.
  3. Check the loaded-entry count. The imported dictionary lasts for this visit; import it again after reloading.

The starter dictionary is small. Plain-text entries and combinations of up to eight strokes are supported. Plover formatting commands, suffix attachment, and steno undo commands are not supported. Edit the transcript directly to correct text.

If something does not work

  • No microphone: open the HTTPS app in Safari, check microphone permissions for the site, and retry. If dictation is unavailable, type in the transcript or try the device keyboard’s microphone.
  • Dictation stopped: keep the page visible and tap Start again. Review the last captured words before continuing.
  • Cloud save failed: check your connection and Google account. If access is denied, check the Firebase permissions. Keep a JSON backup while resolving the error.
  • Device save failed: export a backup before closing the page.

Add to your Home Screen: open Verbatim in Safari, tap Share, then Add to Home Screen. Internet is needed to load the app and use cloud services.
